# Feuerwehr Zugführer Prüfungsplattform

## Start
1. Node.js installieren.
2. Im Ordner ausführen:
   npm install
3. Starten:
   npm start
4. Browser öffnen: http://localhost:3000

## Ausbilder-Demo
Benutzername: ausbilder
Passwort: feuerwehr2026

Für einen echten Server das Passwort über die Umgebungsvariable ADMIN_PASSWORD setzen.

## Hinweis
Die Inhalte stammen aus der bereitgestellten Prüfungsunterlage. Die sechs Multiple-Choice-Fragen werden automatisch mit je 2 Punkten bewertet. Die vier Freitextfragen werden vom Ausbilder mit 0–2 Punkten bewertet. Ab 15/20 Punkten ist die Prüfung bestanden.
